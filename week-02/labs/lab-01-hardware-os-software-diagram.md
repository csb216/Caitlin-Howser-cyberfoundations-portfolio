### Analysis Question 1

If the operating system crashed on the computer you diagrammed, which layer(s) would stop working, and which (if any) would keep working? Explain your reasoning.

### Analysis Question 2

Pick one piece of software you use daily. Trace it down through the OS to the hardware it ultimately depends on. What would happen to that software if the hardware layer failed?

```
I use Apple Music daily. The software would not work because the hardware has to work in order for the software to work. So neither Apple Music, the OS, or the hardware would work on this machine. 
```

### Analysis Question 3

Explain, in your own words, why a cybersecurity professional needs to understand all three layers — hardware, OS, and software — rather than just the software layer where most visible attacks (like phishing emails) happen.

```
If you just understand software, you will not have a full understanding of the entire computer system. Since all these layers work together to make the computer operate correctly, a professional needs to know what happens if one or multiple parts of the system crashes. A thorough understanding of the layers also allows the professional to troubleshoot issues that may arise with hardware, software, or the OS. Knowing what to look specifically for in these situations saves time and can help to address an attack quickly.
```
